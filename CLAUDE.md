# CLAUDE.md

Guidance for Claude Code (claude.ai/code) when working in this repository.

## What this is

Florist - an AI-assisted pricing and workflow tool for florists. The product story lives
in [README.md](README.md); the engineering detail lives in
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Read the second one before changing code.

## The one rule that matters most

`app/index.html` is the **entire application** and the only file to edit. Every copy under
`platforms/*` is generated by `scripts/sync-app.mjs` and git-ignored. Never edit a copy,
and never commit one - the whole point is that five platforms cannot drift apart.

## Language

Documentation and README are **English**. Code comments and commit messages are currently
**Polish** - match whatever the file you are editing already uses rather than mixing both
inside one file. The user interface itself is bilingual (PL/EN) and driven by the `I18N`
dictionaries.

## Conventions that have tests behind them

Breaking any of these fails `npm test`, so fix the code rather than the test:

- **`esc()` on everything user- or model-supplied** that goes into `innerHTML`. Quote
  names, ingredient names, preset names and recognised plant names are all attacker-
  controlled in practice, and in the Electron shells an injected script can read the
  stored OpenAI key.
- **Both dictionaries for every UI string.** A missing `en` key silently renders Polish.
- **Shell copies stay generated and ignored**, and every shell keeps pointing at
  `index.html`.
- **The iOS bridge JavaScript** in `platforms/ios/FloristAI/WebView.swift` is executed by
  the test suite. It lives in a Swift string literal that Xcode never checks.

Other standing rules:

- Hyphens only, no em dashes, anywhere in the project.
- The AI is optional - every OpenAI-backed feature degrades to something useful without a
  key and without a network.
- Ingredient names have one canonical (Polish) form in `NAMES` / `CANON`; display goes
  through `dispName()`.

## Working loop

```bash
open app/index.html     # edit, refresh, repeat - no server, no build
npm test                # Chromium tests; FLORIST_CHROME=/path/to/chrome if needed
```

There are no runtime dependencies. Node and npm exist here only for tests and the helper
scripts in `scripts/`.

## Contributing changes

Work on a branch and open a pull request - CI runs the tests and an Android debug build on
every PR. Do not commit straight to `main`.

README assets are generated, not hand-made: `scripts/screenshots.mjs` for the interface
shots (it switches the UI to English and seeds realistic data) and
`scripts/brand-assets.mjs` for the banner and flow diagram (fonts and logo are pulled from
`app/index.html`). Regenerate them when the interface changes visibly.

## Known open work

The AI generation history in AI Studio is memory-only and disappears on reload, because
three base64 PNGs per generation do not fit in `localStorage`. Moving it to IndexedDB is
the main known piece of unfinished work.
